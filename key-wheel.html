Song attribute ridgelines

Showing — songs. Every attribute is on a 0–1 scale.

Ridges with fewer than 15 songs show each song as a dot instead of a curve, since a curve from so few songs would look more certain than it is.

Color: average popularity of the songs at each point along the curve, stretched to the range shown in this chart.

How to read this chart
  • Each curve is scaled to its own peak, so heights compare shapes, not song counts. The small tick on each ridge marks the median.
  • Tempo, loudness and popularity (used for color) were rescaled within each dataset: 0 is the lowest value in that dataset and 1 the highest, not a real BPM or decibel figure. Spotify popularity is its 0–100 score divided by 100. Because the two datasets were scaled separately, compare their shapes rather than exact values.
  • Key and mode are left out. Key has only 12 possible values and mode is 0 or 1, so a smooth curve would mislead.
  • The color inside each curve changes along it: at each value of the attribute, it shows the average popularity of that ridge’s songs near that value, from white (less popular) through light green to dark green (more popular). Where a curve is very thin there are few songs, so its color there rests on only a handful. Dots are colored by each song’s own popularity.
  • The color scale is stretched to the lowest and highest average popularity in the chart you’re looking at, so it changes as you switch filters: the same color can mean different popularity in two different views. Read the numbers on the legend. Thin tails of the curves (under 5% of their peak) are left out when setting the range. The number beside each era is its overall average.
  • Years are grouped into ranges because most single years have only a handful of songs. Nearly half of my 900 songs are from 2019.
  • The Spotify set has no release years, so the across-years view is only for my 900 songs. Its curves are drawn from 50 bins per genre and attribute. Some tracks are listed under more than one genre, so “All genres” counts them once per genre.

Data. Kaggle “Spotify Tracks Dataset” (maharshipandya): 114,000 rows across 114 genres, 89,741 unique tracks. A track listed under several genres counts once overall and once in each family it belongs to. Popularity is Spotify’s 0–100 score.

Careful. Key and mode are Spotify’s automatic estimates, not a musician’s reading of the score. They often mix up a major key and its relative minor (C major and A minor use the same notes), so treat the major/minor split as approximate. The dataset has no chords and no release dates.
